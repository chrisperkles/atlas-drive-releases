# Atlas Drive for Mac: releases

Atlas Drive shows the Skyline Medien media library (media.skyline.at) in the
Finder sidebar: browse, open files on demand, drag files in.

- **Install:** download the DMG of the latest release, open it and drag
  Atlas Drive to Applications. Then choose Connect… in its menu bar icon.
- **Needs** macOS 14 or later and an Atlas account. Without an account the app
  can do nothing.
- **Updates:** installed copies check `appcast.xml` once a day and update
  themselves (Sparkle, EdDSA-signed).

This repository holds only the signed, notarized releases and the update feed.
The source code is private.
